# 9. Планка сложности

Требование заказчика, добавленное после первой ревизии спека. В коде поле называется `challengeIndex`, в интерфейсе — **Планка**.

## 9.1 Зачем это нужно

Алгоритм повторений из раздела 4.3 решает, **когда** показать слово. Он не решает, **насколько трудным** должно быть занятие. В результате у человека нет ручки громкости: одному скучно, другому тяжело, а продукт ведёт обоих по одному коридору.

Планка даёт эту ручку и делает две вещи сразу. Она подстраивает подбор слов под текущее состояние человека и создаёт ещё одну ось прогресса, которая растёт вместе с ним. Для аудитории, которая боится трудного, важно, что планка **поднимается по её собственному согласию**, а не молча.

## 9.2 Шкала

Целое число от 0 до 30. Стартовое значение 8.

| Диапазон | Название | Что подбирается |
| --- | --- | --- |
| 0–5 | Разминка | Только тир 1, самые знакомые, узнавание из двух вариантов |
| 6–12 | Спокойно | Тиры 1–2, узнавание и выбор из четырёх |
| 13–19 | Рабочая | Тиры 1–3, добавляются сборка из букв и аудирование |
| 20–25 | Плотно | Все тиры, добавляется ручной ввод и ударения |
| 26–30 | Вызов | Все тиры плюс ложные друзья и служебная колода, ввод преобладает |

Тридцать ступеней, а не пять, потому что движение должно быть заметным, но не рывковым. Один шаг почти не чувствуется, три шага чувствуются ясно.

## 9.3 Сложность слова

У каждого слова есть композитная сложность `D` в диапазоне от 0 до 1. Она складывается из трёх частей.

```js
// Насколько слово далеко от русского. Готовое поле tier: 1 близнец, 4 бонус.
const tierNorm = (w.tier - 1) / 3;

// Личная доля ошибок со сглаживанием Лапласа: у нового слова нет истории,
// поэтому оно наследует ожидание от своего тира, а не считается лёгким.
const prior = 0.12 + 0.16 * tierNorm;        // ожидаемая доля ошибок для тира
const PRIOR_WEIGHT = 4;                       // сила априорного мнения в «ответах»
const personal = (w.fail + prior * PRIOR_WEIGHT)
               / (w.ok + w.fail + PRIOR_WEIGHT);

// Ловушки формы: сдвиг ударения, схлопнутый слог, орфография, ложный друг.
const form = Math.min(1,
    (w.stressShift ? 0.4 : 0)
  + (w.syllableDrop ? 0.3 : 0)
  + (w.spellingTrap ? 0.2 : 0)
  + (w.falseFriend ? 0.5 : 0));

const D = 0.40 * tierNorm + 0.40 * personal + 0.20 * form;
```

Личная доля ошибок весит столько же, сколько формальная близость к русскому. Это принципиально: продукт обещает подстраиваться под конкретного человека, а не под усреднённого.

Флаги `stressShift`, `syllableDrop`, `spellingTrap` вычисляются один раз при сборке данных сравнением транскрипции с русским написанием и складываются в `data/words.json`.

## 9.4 Как планка выбирает слова

Планка задаёт не порог, а **полосу** в распределении сложности доступных слов.

```js
function selectByChallenge(pool, challengeIndex) {
  // Только доступные слова: те, что уже в работе или открыты для изучения.
  const ranked = pool.slice().sort((a, b) => difficulty(a) - difficulty(b));
  const center = challengeIndex / 30;          // 0 — самые лёгкие, 1 — самые трудные
  let width = 0.34;                            // полоса шире четверти колоды

  let band = pickBand(ranked, center, width);
  // Если в полосе мало слов, она расширяется, а не сдвигается:
  // сдвиг сломал бы обещание планки, расширение только смягчает его.
  while (band.length < 12 && width < 1) {
    width += 0.12;
    band = pickBand(ranked, center, width);
  }
  return band;
}
```

Полоса, а не порог, потому что занятие целиком из слов одной трудности утомляет. Внутри полосы всегда есть и то, что даётся сразу, и то, что требует усилия.

**Приоритет остаётся у алгоритма повторений.** Слова, у которых подошёл срок, попадают в сессию независимо от планки: забыть выученное хуже, чем поскучать. Планка управляет только тем, чем добираются свободные слоты, а их в типовой сессии от половины до двух третей.

## 9.5 Голос после занятия

На финальном экране, ниже итогов, один вопрос и три кнопки.

```
Как зашло?
╭──────────╮ ╭──────────────╮ ╭──────────╮
│  Легко   │ │  Нормально   │ │  Сложно  │
╰──────────╯ ╰──────────────╯ ╰──────────╯
```

| Ответ | Изменение планки | Что человек видит |
| --- | --- | --- |
| Легко | +2 | «Поднимаю планку. Следующее занятие будет поинтереснее» |
| Нормально | 0 | «Оставляю как есть» |
| Сложно | −2 | «Подберу слова поспокойнее» |

Формулировки важнее механики. При понижении **нельзя** говорить «упрощаю», «стало тяжело» или «снижаю уровень». Мы не сообщаем человеку, что он не справился. Мы сообщаем, что подберём другое.

Голос необязателен. Пропуск равен ответу «нормально» и ничего не сдвигает.

## 9.6 Автоматическая подстройка

Голос человека главнее автоматики, поэтому автоматика работает только когда голоса нет, и только на один шаг.

```js
// Считается по завершённой сессии, применяется если голос не отдан.
if (!voted) {
  const share = correctFirstTry / answered;
  const fast  = medianAnswerMs < 2200;
  if (share >= 0.92 && fast) challengeIndex += 1;      // явно скучно
  else if (share <= 0.55)    challengeIndex -= 1;      // явно тяжело
}
challengeIndex = clamp(challengeIndex, 0, 30);
```

Ограничения, которые защищают от дёрганья:

- Не более трёх пунктов изменения за один день, в сумме по голосам и автоматике.
- После понижения планка не поднимается автоматически в течение суток. Человеку, которому было тяжело, не поднимают нагрузку через полчаса.
- Планка никогда не меняется во время сессии.

## 9.7 Ручное управление

В профиле, в настройках занятий, ползунок от 0 до 30 с живой подписью.

```
Планка                                    14
├────────────────●───────────────────────────┤
Разминка          Рабочая              Вызов

Сейчас: тиры 1–3, добавлены сборка из букв и аудирование.
Планку двигает и приложение, если ты голосуешь после занятий.
```

Ручное значение имеет приоритет: после ручной установки автоматическая подстройка выключается на три дня, чтобы человек увидел результат своего выбора, а не борьбу с алгоритмом.

Рядом переключатель «Подстраивать автоматически», по умолчанию включён.

## 9.8 Что будет дальше

Заказчик прав в том, что планка выше двадцати пяти упирается в потолок контента: 200 когнатов физически не могут быть трудными. Поэтому высокие ступени наполняются по мере роста словаря.

| Источник | Когда подключается | Готовность |
| --- | --- | --- |
| Тиры 3 и 4 текущей колоды | с планки 13 | уже есть |
| Ложные друзья | с планки 20 | данные есть, нужны недостающие поля |
| Служебная колода | с планки 22 | собирается сейчас |
| Слова, отдалённо похожие на русский | с планки 26 | будущий контент |
| Слова без сходства с русским | с планки 30 | будущий контент |

Это и есть ответ на вопрос «что делать с человеком, который прошёл всё». Планка превращает исчерпание контента из обрыва в приглашение: сначала кончаются лёгкие слова, а не слова вообще.

## 9.9 Что планка не делает

- Не влияет на XP и алмазы. Иначе она превратится в способ фармить награды на низкой сложности, и человек будет выбирать не то, что ему полезно, а то, что выгодно.
- Не влияет на стрик и жизни.
- Не показывается как «уровень игрока». Уровень и грейд из раздела 3.7 отражают пройденный путь, планка отражает текущую настройку. Их нельзя смешивать: иначе низкая планка начнёт читаться как низкий статус, а это ровно то чувство, которое продукт лечит.

}
