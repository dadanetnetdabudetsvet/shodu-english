# Сходу

Веб-приложение для изучения английских слов. Ставится на домашний экран, работает офлайн, ничего не спрашивает и никуда не отправляет.

**Открыть:** https://dadanetnetdabudetsvet.github.io/shodu-english/

## В чём идея

Это не курс. Продукт начинается с ревизии того, что человек уже знает: первые двести слов — русско-английские когнаты вроде `pizza`, `doctor`, `taxi`. Их не учат, их узнают. Первое занятие не учит, а считает.

Когда лёгкие слова кончаются, подключается вторая колода из ста двадцати служебных слов: артикли, глаголы, связки, предлоги. Из существительных нельзя составить предложение, из служебных слов — можно.

## Что внутри

| | |
| --- | --- |
| Контент | 200 когнатов, 120 служебных слов, 30 ложных друзей, 30 правил, 12 шаблонов фраз |
| Механики | Занятие, Блиц, На слух — три разных режима на общем движке |
| Повторения | Коробки Лейтнера с фаст-треком по времени ответа |
| Планка | Шкала 0–30, голос после занятия, автоподстройка, ручная настройка |
| Мотивация | Ритм недели, стрик, две жизни, очки, алмазы, уровни, 12 медалей |
| Платформа | Установка на домашний экран, офлайн, две темы, синтезированный звук |

## Принципы

Правила, которым подчиняется весь код, лежат в [docs/spec/00-rules.md](docs/spec/00-rules.md). Коротко: человеку никогда не сообщают, что он не справился; проиграть за один день невозможно; проценты точности не показываются нигде; числа на экране всегда посчитаны из данных, а не назначены.

## Разработка

```bash
node serve.mjs        # http://localhost:5173
node check.mjs        # инварианты кода и данных
npm i --no-save jsdom && node smoke.mjs   # сквозной прогон сценария
```

Слой `src/domain/` не знает про DOM и хранилище, это проверяется автоматически.
