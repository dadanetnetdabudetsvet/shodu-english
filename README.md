# Сходу

Веб-приложение для изучения английских слов. Ставится на домашний экран, работает офлайн, ничего не спрашивает и никуда не отправляет.

**Открыть:** https://dadanetnetdabudetsvet.github.io/shodu-english/

## В чём идея

Это не курс и не образовательный продукт. Категория точнее звучит так: восстановление самооценки через доказуемое действие. Человек приходит не за английским, а за тем, чтобы перестать быть человеком, который его не выучил.

Поэтому продукт начинается с ревизии того, что уже есть. Первые двести слов — русско-английские когнаты вроде `pizza`, `doctor`, `taxi`. Их не учат, их узнают. Первое занятие не учит, а считает.

Когда лёгкие слова кончаются, подключаются служебные: артикли, глаголы, связки, предлоги. Из существительных нельзя составить предложение, из служебных слов — можно.

## Что внутри

| | |
| --- | --- |
| Слова | 1000 в шести колодах: когнаты, служебные, дальние когнаты, глаголы и признаки, обычные существительные, ложные друзья |
| Правила | 300, отсортированы от полного совпадения с русским к настоящим отличиям |
| Режимы | Занятие, Блиц, На слух, Фраза, Поток |
| Повторения | Коробки Лейтнера с ускорением по времени ответа |
| Сложность | Шкала 0–30: голос после занятия, автоподстройка, ручной ползунок |
| Мотивация | Ритм недели, стрик, две жизни, очки, алмазы, уровни, медали |
| Языки | 19 языков интерфейса, определяется по браузеру |
| Платформа | Установка на домашний экран, офлайн, две темы, синтезированный звук |

## Пять режимов

- **Занятие** — карточка нового слова, затем проверки. Единственный режим, где вводятся новые слова и работают жизни.
- **Блиц** — быстрый выбор из двух, на скорость. Есть вариант без таймера.
- **На слух** — слово звучит, написания на экране нет.
- **Фраза** — сборка предложения из плиток. Это черновик, а не ответ: перестановки бесплатны, жизней нет.
- **Чтение** — строка с одной подменой, надо её поймать. Тип мышления здесь не извлечение из памяти, а проверка.

## Принципы

Правила, которым подчиняется весь код, лежат в [docs/spec/00-rules.md](docs/spec/00-rules.md). Коротко:

- человеку никогда не сообщают, что он не справился;
- проиграть за один день невозможно;
- проценты точности не показываются нигде;
- все счётчики только растут;
- любое число на экране посчитано из данных, а не назначено;
- учебный контент не продаётся за валюту.

Полный набор приёмов, которыми продукт держит в человеке ощущение, что он уже знает английский, — в [docs/spec/11-ideology.md](docs/spec/11-ideology.md): тринадцать механик, словарь обязательных и запрещённых слов, шесть запретов.

«Сходу Всё» — пожизненный доступ за троих приведённых друзей. Внутри только облик, защита ритма и удобства: ни слова, ни правила за него не закрываются. Цена в 30 долларов показана зачёркнутой как мера подарка — денег мы не берём нигде.

Подтасовка запрещена отдельно и с обоснованием: улика, пойманная на подделке, обесценивает задним числом весь предыдущий прогресс. Подкручивать можно только состав вопросов, никогда результат.

## Разработка

```bash
node serve.mjs                            # http://localhost:5173
node check.mjs                            # инварианты кода, данных и переводов
npm i --no-save jsdom && node smoke.mjs    # сквозной прогон в настоящем DOM
node screens-check.mjs                     # все экраны без ошибок, «Сходу Всё», сторож поломок
node wordsets-check.mjs                    # любая подборка даёт занятие в любом режиме
npx playwright install webkit && node safari-check.mjs   # прогон в движке Safari, эмуляция айфона
node standalone-check.mjs                  # вводная проверка в приложении с домашнего экрана
node tools-sw-manifest.mjs                 # пересборка списка офлайн-кэша
node tools-i18n-extract.mjs                # каталог строк для переводчиков
node tools-merge-decks.mjs                 # сводка по колодам и дублям
```

Слой `src/domain/` не знает про DOM и хранилище, это проверяется автоматически.
